# 🎯 IT技术面试助手平台

本仓库包含两个互补的面试相关项目：

---

## 📂 项目结构

```
├── IT面试助手/         ← 面试官Bot（给HR/面试官用）
│   ├── PERSONA.md      ← 人设配置
│   ├── COZE_DEPLOYMENT.md  ← 扣子部署指南
│   ├── DEPLOYMENT.md   ← 本地部署指南
│   └── README.md       ← 项目说明
│
└── 应聘搭子/           ← 应聘者Bot（给求职者用）
    ├── PERSONA.md      ← 人设配置
    ├── COZE_DEPLOYMENT.md  ← 扣子部署指南
    └── README.md       ← 项目说明
```

---

## 🤖 IT面试助手

**定位：** 帮面试官面试候选人 / 帮求职者练习面试

**GitHub：** [打开IT面试助手文件夹](https://github.com/yan-124/yan/tree/main/IT%E9%9D%A2%E8%AF%95%E5%8A%A9%E6%89%8B)

**特点：**
- 10年经验面试官视角
- 口语化、真实面试风格
- 连环追问3-5层
- 支持测开+安全工程两大领域

**使用场景：**
- HR/技术主管面试候选人
- 求职者练习面试

---

## 🤝 应聘搭子

**定位：** 帮求职者回答面试问题

**GitHub：** [打开应聘搭子文件夹](https://github.com/yan-124/yan/tree/main/%E5%BA%94%E8%81%98%E6%90%AD%E5%AD%90)

**特点：**
- 言简意赅，句句在点上
- 结构化回复又不失幽默
- 专业但不炫技
- 针对高级岗位（架构师等）

**使用场景：**
- 求职者准备面试答案
- 分析简历，给出针对性建议
- 练习回答技巧

---

## 🚀 快速开始

### 1. 选择你要用的项目

| 如果你是... | 使用 |
|-------------|------|
| HR/面试官 | [IT面试助手](https://github.com/yan-124/yan/tree/main/IT%E9%9D%A2%E8%AF%95%E5%8A%A9%E6%89%8B) |
| 求职者 | [应聘搭子](https://github.com/yan-124/yan/tree/main/%E5%BA%94%E8%81%98%E6%90%AD%E5%AD%90) |

### 2. 部署到扣子

每个项目文件夹里都有 `COZE_DEPLOYMENT.md` 部署指南

---

## 💡 配套使用

两个Bot配合使用效果最佳：

1. **准备阶段** → 用「应聘搭子」帮你准备答案
2. **练习阶段** → 用「IT面试助手」模拟面试
3. **复盘阶段** → 再用「应聘搭子」分析改进
