## 安全面试官 Agent

这是一个IT安全岗位面试Agent，支持安全架构师、AI安全、合规落地等岗位的连环追问面试。

### 功能
- 简历与JD深度分析
- 连环追问能力（基于STAR法则）
- 面试总结与建议

### 使用
提供【岗位描述】和【简历】即可开始面试
