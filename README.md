# 🛡️ IT面试助手

**测开与安全工程领域的智能化人才评估平台**

一个专业级的IT技术面试助手，基于10年+技术面试经验打造，覆盖**测试开发**与**安全工程**两大核心技术领域。采用真实面试官风格，口语化、自然、不整虚的。

## 💬 真实面试风格

**和其他AI助手不一样的地方：**

- ✅ 口语化，像真人聊天
- ✅ 追问3-5层深挖细节
- ✅ 问实际工作场景的问题
- ✅ 不会格式化输出、堆砌emoji
- ✅ 问题来自真实面试经验

**面试官会这样问你：**

```
行，那我们直接开始。第一个问题：
你最近挖到过印象最深的漏洞是什么？讲清楚发现场景、利用过程、危害等级。

追问：你说登录框的注入是吧？当时目标站有没有WAF？你怎么绕过的？
```

## 📝 面试题库示例

### 测试开发面试题

**初级测开：**
- 你用什么框架写自动化？Selenium还是Playwright？
- 给你一个登录功能，怎么设计测试用例？
- 自动化用例稳定性怎么保证？遇到什么坑？
- 怎么定位bug？

**中级测开：**
- 你设计过自动化框架吗？架构什么样？
- 怎么做接口自动化？用什么工具？
- 性能测试做过吗？用什么工具？
- 搞过CI/CD集成吗？Jenkins pipeline怎么写？

**高级测开：**
- 主导过测试平台建设吗？包含哪些功能？
- 如何衡量测试团队价值？ROI怎么算？
- 测试左移做了吗？怎么落地？
- 从零搭建测试体系，怎么规划？

### 安全工程面试题

**1-3年经验：**
- 你挖到过什么漏洞？印象深刻能讲讲的？
- SQL注入有几种利用方式？盲注怎么判断？
- 你用过哪些扫描工具？有什么不好用的？
- 内网渗透什么思路？实际操作过吗？
- WAF怎么绕？

**3-5年经验：**
- 你平时怎么处理告警？能讲个case吗？
- 误报怎么处理？优化过规则吗？
- 应急响应做过吗？怎么定位的？
- 关注威胁情报吗？用什么渠道？

**5年+经验：**
- 你设计过什么安全架构？为什么这么设计？
- 零信任落地了吗？遇到什么问题？
- 等保怎么做的？踩过什么坑？
- 安全预算怎么申请？

## 🎓 场景题（所有级别）

### 测试场景
- 自动化用例突然全部失败，怎么处理？
- 开发说"这个功能我改了，不影响其他功能"，怎么验证？
- 测试环境和生产环境数据不一致，怎么处理？
- 上线前发现bug来不及修，怎么办？
- 如何快速回归一个支付模块的核心功能？

### 安全场景
- 发现服务器被黑了，第一步做什么？
- 突然收到勒索邮件，怎么办？
- 0day爆了，第一时间做什么？
