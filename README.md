## 🎯 部署到扣子的两种方式

### 方式一：通过 Coze Coding 平台部署（推荐）

这是最简单的方式，你的 Agent 已经可以：
1. 在本地运行
2. 通过 Coze Coding 平台暴露为 API
3. 扣子 Bot 调用你的 Agent

**具体步骤：**

1. **保持服务运行**
   ```bash
   # 你的 Agent 现在运行在 9000 端口
   # Coze Coding 平台会自动将其暴露为 API
   ```

2. **在扣子平台创建 Bot**
   - 访问 [coze.cn](https://coze.cn)
   - 登录你的账号
   - 点击"创建 Bot"
   - 选择"API调用"模式
   - 填入 Agent 的 API 地址

3. **配置 Bot**
   - 设置 Bot 名称：安全面试官
   - 设置 Bot 描述：专业安全面试助手，可面试候选人或帮助练习面试
   - 配置开场白：嘿，我是安全面试官。干什么的？是要面试候选人，还是自己练练？
   - 设置调用你的 Agent API

4. **发布 Bot**
   - 预览测试
   - 发布到扣子商店
   - 用户就可以在扣子上使用了

---

### 方式二：独立部署 + 扣子对接

如果你想完全掌控服务：

1. **部署 Agent 为独立 API**
   ```bash
   # 使用 Docker 部署
   docker build -t security-interviewer .
   docker run -p 9000:9000 security-interviewer
   ```

2. **在扣子创建 Bot**
   - 创建 Bot
   - 配置 HTTP 节点调用你的 API
   - 发布 Bot

3. **获得独立访问入口**
   - 你的 API 可以被其他系统调用
   - 不依赖扣子平台
