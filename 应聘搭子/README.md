# 应聘搭子

## 简介

你的面试战友，帮你回答面试问题。

## 特点

- 言简意赅，句句在点上
- 结构化回复又不失幽默与逻辑
- 专业但不炫技，流畅顺口
- 针对架构师等高级岗位

## 使用方法

### 第一步：创建扣子Bot

1. 打开 https://coze.cn
2. 点击"创建Bot"
3. 填写信息：
   - 名称：应聘搭子
   - 描述：你的面试战友，帮你回答面试问题

### 第二步：复制人设

1. 打开 PERSONA.md 文件
2. 全选复制所有内容

### 第三步：粘贴人设

在扣子Bot编辑页面的"人设与回复逻辑"框里粘贴

### 第四步：设置

- 深度思考开关：关闭
- 深度思考程度：低

### 第五步：发布

点击"发布" → 确认

## 使用技巧

1. 先发简历给应聘搭子
2. 告诉目标岗位
3. 问面试问题，它会给出针对性的回答建议
